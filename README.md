# D&A Doce Amor — Bolos, Festas e Sobremesas Artesanais

Site institucional e catálogo digital da confeitaria artesanal **D&A Doce Amor**, localizada na Vila Carmosina, Itaquera – São Paulo/SP.

## 🍰 Sobre o Projeto
Plataforma moderna, minimalista e responsiva desenvolvida em **Next.js 14**, com:
- **Catálogo Interativo**: Filtro por categorias (*Mais Pedidos*, *Bolos de Festa*, *Caseirinhos*, *Sobremesas Geladas* e *Corporativo*).
- **Calculadora de Festa**: Dimensionamento aproximado de peso de bolo em kg baseado no número de convidados, com link de orçamento pré-preenchido para o WhatsApp.
- **Quebra de Objeções**: Seção de FAQ interativa e depoimentos 5 estrelas verificados dos apps de delivery.
- **Integração de Deliverys**: Links diretos e selos personalizados para iFood, 99Food e Keeta.
- **Tipografia Artesanal**: Fonte primária *Cookie* e secundária *Inter*.
- **Ícones Personalizados**: Biblioteca SVG minimalista desenhada exclusivamente com as cores e elementos gráficos da marca.

## 🚀 Tecnologias
- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Linguagem**: [TypeScript](https://www.typescriptlang.org/)
- **React**: 18
- **Estilização**: CSS puro modular com tokens de design e variáveis semânticas
- **Ícones**: SVGs customizados inline

## 🛠️ Como Executar Localmente

```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento
npm run dev

# 3. Gerar a compilação de produção
npm run build

# 4. Iniciar a versão de produção
npm start
```

Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.
